| 측정 | 40G 케이스 | 80G + 50cm | 80G + 30cm | 내장 512GB (73% 사용) |

| Amorphous SEQ1M QD1 읽기/쓰기 | 3,046 / 3,103 | 4,353 / 4,012 | 4,329 / 3,943 | 3,442 / 4,407 |
| Amorphous RND4K QD64 읽기/쓰기 | 638 / 273 | 644 / 286 | 664 / 291 | 1,130 / 120 |
| Blackmagic 쓰기/읽기 | 3,509 / 3,269 | 4,685 / 5,137 | 4,694 / 5,120 | 4,044 / 5,223 |

- 80G 교체 효과: 큰 파일 읽기 +64%, 쓰기 +34%. 작은 파일(RND4K)은 변화 없음(SSD 반응속도가 한계).
- 케이블 50cm vs 30cm: 차이 1% 미만 = 측정 오차. 50cm 사용.
- 내장 대비: 큰 파일은 동등~우세, 작은 파일 읽기는 내장 우세 → 작업 파일·대용량은 외장, 시스템·앱은 내장.
- 측정 도구 차이: Amorphous QD8 = 동시 요청 8개(최대 성능), Blackmagic = 5GB 연속 기록(실제 복사 체감에 가까움).

## 6. 정기 점검 (월 1회)
```bash
diskutil list external          # 디스크 번호 확인(연결마다 바뀔 수 있음)
sudo smartctl -H diskN          # 종합 판정
sudo smartctl -t short diskN    # 2분 자가진단
sudo smartctl -a diskN          # 전체 리포트
```
- smartmontools 설치: `brew install smartmontools`
- 외장에서 안 읽히면: `sudo smartctl -a -d nvme diskN`
- 비교 측정은 같은 도구·같은 설정(Amorphous 5회 / 1GiB)으로.
