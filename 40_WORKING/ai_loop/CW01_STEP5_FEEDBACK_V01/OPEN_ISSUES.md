# CW-01 후속 검토 항목

| 항목 | 상태 | 확인에 필요한 근거 |
|---|---|---|
| 초기 상태 맥락 격리 | CONTEXT_ISOLATION_UNVERIFIED | 프로젝트·개인화·메모리·이전 맥락 유입의 독립 확인 |
| T0→T1 복원 시간 | NOT_MEASURED | 동일 관찰 시계의 실제 전송·최초 응답 완료 시각 |
| 제출 본문 동일성 | 미확인 | 실제 수신 입력과 승인 파일의 대조 |
| 기술적 쓰기 차단 | 미검증 | 도구 권한 또는 운영체제 수준 쓰기 제한의 근거 |
| 전체 저장소 무결성 기준 검증 및 백업 복원 | 미검증 | 별도 기준 해시·복원 시험. Step 5-A 전후 비교는 작업 중 변화만 확인 |
| Claude 독립 재현 | 미검증 | 승인된 Claude 수신 환경과 독립 도구 출력 |
| 출력 지시의 효과와 최초 해시 누락 원인 | 미확정 | 통제된 조건과 반복 비교 |

Step 5-B에서 증거 계보와 규격·정책 후보를 독립 검토한다. 공식 승격은 Step 5-C의 별도 승인 대상이다.
