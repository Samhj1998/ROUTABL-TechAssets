# CW-01 인계 출력 규격 후보 v0.1

검토 후보. 공식 CW-01 v1.0은 별도 승인으로 관리한다.

| 필드 | 작성 기준 |
|---|---|
| 자산 ID | 인계 기준 ID |
| 상대경로 | 저장소 기준 경로. 기준 저장소는 별도로 표시 |
| 기대 SHA-256 | 인계 출처에서 받은 전체 64자리 |
| 실측 SHA-256 | 원본 바이트로 직접 계산했을 때만 전체 64자리 기록 |
| 검증 상태 | REFERENCE_REPRODUCED, DIRECT_HASH_VERIFIED, HASH_MISMATCH, NOT_ACCESSIBLE, NOT_TESTED |
| 방법·수행자·시각 | 사용한 도구·명령, 수행 역할 또는 세션, 시간대 포함 시각, 도구 결과의 위치 |

수신 답변은 각 자산의 ID·상대경로·기대 해시·검증 상태를 한 행에 적는다. 참조만 재현했다면 REFERENCE_REPRODUCED로 표시하고 실측값은 비워 둔다. 직접 계산했으면 실제 도구 출력과 실측값을 연결한다. 접근 실패와 불일치를 구분하고, 확인할 수 없는 시각·환경은 미확인으로 기록한다. 별도 실행의 증거와 승인 기록을 합치지 않는다.
