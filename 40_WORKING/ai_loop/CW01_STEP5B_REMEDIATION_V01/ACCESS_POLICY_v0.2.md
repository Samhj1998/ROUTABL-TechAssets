# CW-01 기술자산 접근 정책 후보 v0.2

ChatGPT와 Claude가 업무에 필요한 기술자산 원본을 최대한 검색·열람할 수 있게 한다. 기존 ASSET_SECURITY_AND_SEARCH_POLICY_v0.1.md의 제한을 적용하고, 이 문서는 승인된 직접 활용의 판단 기준을 보완한다.

| 등급 | 기존 검색 색인 기준 | 승인된 직접 원본 접근 기준 |
|---|---|---|
| P0 | 경로와 내용 모두 제외 | 비밀번호·인증 토큰·개인키·복구키·Admin SDK 자격증명을 별도 보호한다. AI 열람 및 전송 범위에서 제외한다. |
| P1 | 기본 원문 제외 | 고객정보·실거래·정산 원본이 필요한 실제 업무에서 승인된 목적·접근 주체·환경에 한해 정확한 원본의 필요한 최소 범위를 활용한다. 민감한 고객 원본자료의 외부 공유 제외 규정을 적용한다. |
| P2 | 안전한 경로·크기·해시 등 메타데이터 위주 | 업무상 필요한 원본은 자료별 비밀 포함 여부와 권한을 확인해 읽기 범위를 정한다. 원문 색인 확대는 별도 사안이다. |
| P3 | Mac 로컬 내용 검색, 식별정보 치환, 비밀 감지 시 원문 제외 | 일반 기술 원본을 업무 범위에서 활용한다. AI 서비스 전송 여부는 수신 환경과 적용 정책을 별도로 확인한다. |

색인 등급은 검색 결과에 무엇이 표시되는지 정한다. 직접 열람은 승인된 업무에서 누가 어디에서 어떤 원본을 사용할 수 있는지 정한다. 두 통로를 따로 심사하며 검색 결과를 읽기 권한으로 해석하지 않는다. 비밀 문자열 자동 검사는 보조 수단이다.

| 행위 | 승인 판단 |
|---|---|
| 로컬 읽기·해시 계산 | 읽기 권한 및 대상 범위를 확인한다. 해시만 반환하면 원문 전송과 분리해 기록한다. |
| AI 서비스 전송 | 원문·발췌·해시 등 실제 전달 항목, 수신 서비스, 목적, 접근 조건을 구분한다. P0 및 기존 정책이 외부 공유에서 제외한 민감한 고객 원본은 보낸다는 승인만으로 예외 처리하지 않는다. 정책 충돌 시 기존 제한을 적용하고 Chat에서 별도 정책 판단을 받는다. |
| 제3자 제공 | 사람이거나 조직인 구체적 수신자, 전달 항목과 권한을 별도로 확인한다. AI 서비스 전송 승인과 구분한다. |
| 공개 배포 | 공개 채널, 공개 범위, 배포 승인 및 결과를 별도로 기록한다. |

읽기, 수정, 삭제, 운영 적용, 배포 권한은 각각 분리한다. 범용 셸에서 읽기 명령으로 범위를 지킨 경우와 운영체제가 쓰기를 차단한 경우를 구분한다. 이 후보 문서의 채택은 검색 색인 설정, 기존 정책, 실제 권한을 자동으로 변경하지 않는다.
