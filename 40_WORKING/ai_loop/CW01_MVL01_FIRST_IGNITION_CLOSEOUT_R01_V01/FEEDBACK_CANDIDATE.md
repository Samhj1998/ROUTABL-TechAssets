# MVL-01 검색 출처 검증과 환류 후보 v0.1

자산 ID: MVL01-FEEDBACK. 이 후보의 등록 범위는 Mac Studio 격리 색인이다.

## 무엇을 개선했는가

운영 v1.5의 출처 연결은 v0.6을 읽는다. v0.27과 대조한 결과 출처 연결 두 건은 동일했고 대장 자산 행은 24건에서 162건으로 늘었다. 기존 v0.6 사용 자체가 오동작이라는 근거는 없었다. 격리판은 v0.27을 숫자 판본·스키마·SHA-256으로 확인하고 기존 v1.5 검색에 원본 검증을 연결한다.

기존 한국어 별칭, 점수, 그룹 순서, 중복 묶음 및 수동 증거 표시를 비교했다. 기존 v1.4에서 SQLite 무결성 검사를 재사용했다. CW-01의 ID·출처·해시 인계 구조를 채택했다. AF-01은 로컬 CLI와 불필요한 전송 없는 접근에 적용했다.

## 실패 조건과 처리

원본 없음, 인덱스 해시 불일치, 원본 변조, 링크를 통한 경로 대체는 직접 검증 성공으로 표시하지 않는다. 더 높은 미승인 대장, 핀 변조, 숫자 판본 충돌은 대장 선택을 중단한다. 새 로컬 자료는 메타데이터만 색인하고 기본 인계에 자동 추가하지 않는다.

## 재사용

이 문서의 ID를 검색하면 로컬 출처와 실제 바이트 SHA-256을 확인할 수 있다. 최종 인계의 환류 항목은 기존 검색 엔진의 조회 결과에서 생성한다. 독립 수신 및 운영 배포는 별도 상태로 기록한다.
