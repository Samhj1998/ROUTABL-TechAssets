# Step 2-C2 최소 승인안

C1의 합성 Seatbelt 시험은 Claude 프로세스의 격리를 검증하지 않았다. C2는 실제 Claude 도구 요청과 거부 증거를 얻기 위해 승인된 모델 호출이 필요하다. 다음 순서를 121 Chat에서 결정한다.

1. **실행 경계 선택 및 무호출 검증.** 별도 macOS 표준 사용자 또는 동등하게 Claude 프로세스 전체를 격리하는 실행 수단을 고른다. 원본 홈·저장소·마운트·자격증명 차단, 입력 읽기 전용, 출력·scratch 쓰기 허용, 승인된 네트워크 경로를 무해한 시험 파일로 먼저 검증한다. 계정 생성·기존 권한 변경·새 OAuth가 필요한 경우 해당 변경을 따로 승인한다. 검증 실패 시 모델 호출 단계 보류.
2. **파일 도구 1차.** 개인 Pro·크레딧 비활성 및 인증 우회 변수 부재 확인 후, 합성 전용 경로의 한 세션과 고정 합성 프롬프트 한 건을 승인한다. --restricted, --safe-mode, --no-chrome, 빈 MCP 후보와 --strict-mcp-config, 내장 도구 명시 목록을 검토한다. 필요한 도구만 제공하고 Bash는 1차에서 제외한다. 내장 Read의 허용·거부, Edit/Write의 입력 차단 및 출력 허용, ../와 링크에 대한 거부를 합성 파일에서 시험한다. 세션의 도구 목록에 MCP가 없음을 증거로 남긴다. 관리 정책이나 예상 외 MCP·호스트가 확인되면 중단한다.
3. **셸 도구 2차.** 필요한 경우 별도 선택으로 Bash에 고정 합성 프롬프트 한 건을 승인한다. Claude 셸 샌드박스 강제, 우회 및 재시도 금지, 최소 명령·네트워크 허용 정책을 실제 버전에서 확인한다. 명시적인 권한 허용 없이 외부 서비스에 연결하지 않는다. 예상 경계 이탈, 비용 경고, 권한 확대 요청 시 중단한다.
4. 호출 한도는 1차 최초 프롬프트 1건, 선택 2차 최초 프롬프트 1건이며 도구 요청에 이어지는 모델 왕복은 발생할 수 있다. 승인 시 최대 왕복 또는 도구 호출 수도 함께 정한다. PASS는 도구 요청과 실제 허용/거부 로그로만 판정하며, 요청이 생략되면 NOT_TESTED로 둔다.

실행 후보 옵션은 도움말에서 확인했지만 조합의 실효 정책은 미검증이다. --bare는 Pro OAuth를 읽지 않으므로 제외한다. 합성 데이터와 고정 프롬프트만 전송 범위에 명시한다. 공통 기술자산·원본·보류시험·운영 질의·외부 MCP 연결·B/C 개발은 별도 승인 대상이다.
