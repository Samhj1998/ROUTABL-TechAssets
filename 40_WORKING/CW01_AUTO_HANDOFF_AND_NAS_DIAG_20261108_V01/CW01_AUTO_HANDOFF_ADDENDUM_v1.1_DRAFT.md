# Digitopia CW-01 v1.1 개정 후보 — 자동 인계문 필수 출력

상태: 격리 기술자산 후보 / ChatGPT 프로젝트 지침 및 공식 대장 미반영
작성일: 2026-11-08 KST
이전 판본: 00_GUIDE/DIGITOPIA_CHAT_WORK_PROTOCOL_v1.0.md (기존 파일 변경 금지)
개정 근거: 독립 Work R01의 120-2-W 결과 수동 반환 프롬프트가 최초 종료 응답에서 자동으로 제시되지 않아 사용자가 작성하도록 요청받은 사례. 기존 CW-01은 Chat↔Work 쌍만 명시하고 Work→다른 Work의 독립 수신 결과 반환을 명시적으로 강제하지 않았음.
적용 대상: 같은 번호의 Chat↔Work, 독립 Work 수신자, 추가 검증 Work, 정기 점검/예약 작업의 실패·사고 조사.

## 최상위 원칙

AI가 인계에 필요한 문서·프롬프트를 직접 작성한다. 사용자는 복사·전달·승인만 한다. 인계 프롬프트 작성을 사용자에게 부탁하는 것은 불허한다.

## 자동 인계 출력 규칙

1. Chat→Work: 사용자가 설계·승인 또는 실행할 다음 작업이 생기면 AI가 Work 전용 완결 프롬프트를 응답의 마지막에 **자동** 출력한다. 구체적 목표, 승인 범위, 기존 자산과 해시, 산출물, 금지 경계, 성공 기준, 보고 형식을 포함한다.
2. Work→Chat: 설계 판단, 범위 확대, 주요 위험, 최종 PASS/PARTIAL/FAIL 판정이 필요한 경우 AI가 Chat용 검토 프롬프트를 **자동** 출력한다.
3. Work→Work / 독립 Work→원 Work: 다른 Work에 결과를 돌려주거나 후속 검증·환류를 맡겨야 할 때, 독립 수신 AI 자신이 지정 수신 Work에 바로 붙일 수 있는 완결 프롬프트를 **자동** 출력한다. 별도 요청을 기다리거나 사용자에게 작성하라고 말하지 않는다.
4. 보안·백업 정기 점검의 실패·불일치·미백업 위험: (A) Chat 판단용 완결 프롬프트와 (B) Work 읽기 전용 조사용 완결 프롬프트 **2개를 모두 자동** 출력한다. 실제 운영 변경/재백업이 필요하면 읽기 전용 조사와 분리하고 새 승인이 필요함을 명시한다.
5. 수신 채팅은 이전 대화·파일을 자동으로 보지 못한다고 가정한다. 인계 대상 세션명과 목적, 장치 ID, 정확한 폴더·파일 경로, 기대/실측 SHA-256, 성공·실패·미검증의 출처와 시각, 재현 명령, 승인·변경 금지, 반환 형식을 포함한다.
6. 인계 대상이 불분명하면 기본 수신자를 명시적으로 지정해 내보내되, 실제로 새 권한을 창설하지 않는다. 이전 승인 내에서 계속하면 인계 없이 '현재 모드 계속'을 보고한다. 검증 완료로 종료하면 인계가 필요 없음을 명시한다.
7. 실행·도구·접근이 실패하거나 일부만 완료돼도 지금까지 검증된 근거와 미해결 범위에 맞춰 **최소한의 실효적 다음 단계 프롬프트**를 자동 작성한다. 근거가 없는 SHA-256·경로·성공 주장은 금지한다.
8. 인계 프롬프트는 결과 보고와 별개의 완결된 '복사해 붙여넣을 수 있는' 산출물이어야 한다. 코드블록·글쓰기 블록으로 제공해 사용자가 손으로 재작성할 필요가 없어야 한다.

## 자동 인계 2종 기본 구조

### A. 판단·승인 검토용 Chat 인계
- 왜 Chat 판단이 필요한가
- 이번 세션에서 독립적으로 검증한 결과와 증거
- 미확인 상태, 실패 원인에 대한 관찰과 추정 분리
- 선택안·위험·추천안
- Chat이 결정할 질문
- Chat에 그대로 입력할 완결된 프롬프트

### B. 실행·검증용 Work 인계
- 어떤 작업을 왜 실행하는가
- 대상 장치·파일·SHA·실제 재사용 자산
- 명시적 읽기/쓰기 권한·중단 조건
- 작업 순서·독립 시험·성공 판정
- 미확인 사항 및 비가역적 변경 금지
- 산출물·증거 보관·Chat으로의 수동 반환 양식
- Work에 그대로 입력할 완결된 프롬프트

## 검증과 릴리스 경계

이 문서는 기술자산 정책 변경 **초안**이다. 이번 저장은 ChatGPT 프로젝트 지침, 원래 CW-01 v1.0, 공식 기술자산대장 및 Step 5-C 게시의 자동 변경이 아니다. 프로젝트 지침의 실제 반영은 사용자가 ChatGPT 프로젝트 설정에서 이 내용을 추가해야 한다. 독립 Work/예약 작업에는 실행 프롬프트 및 예약 작업 지침에 직접 포함해야 한다.

시범 적용 검증: 독립 Work가 종료 시 Work→Work 수동 반환 프롬프트를 직접 출력하는지, 백업 오류 통지가 Chat 판단 및 Work 조사용 2개 프롬프트를 스스로 출력하는지 확인한다.
