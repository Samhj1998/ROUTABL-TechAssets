파일 시험 C1의 기대값과 새 합성 대조 각 12/12 일치. 보호된 다세대 프로세스에서 관측한 12건은 실제 OS 거부 EACCES/EPERM에 해당한다. 네트워크는 127.0.0.1과 새 합성 폴더 Unix 소켓만 사용했고 외부 주소·DNS 접속은 없었다. 시험 임시 링크·소켓·표식은 제거했다.
