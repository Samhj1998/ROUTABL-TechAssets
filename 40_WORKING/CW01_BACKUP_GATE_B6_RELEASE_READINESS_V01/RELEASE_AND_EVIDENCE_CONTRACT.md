## 운영 적합성 기준

- 실제 Gate·선택기·CAS 호출과 원본 영수증 정규화, 독립 선택 수집을 승인된 환경에서 검증한다. 정상 백업 중 로컬 영수증의 바이트 해시와 최소 증거를 확보한다. 신뢰된 수집기가 실행 전·후 선택 및 현재 대장을 산출한다. 외부 JSON의 보고값을 독립 수집으로 인정하지 않는다.
- NAS 매니페스트 SHA와 연결된 구성요소를 지정 참조별로 전수 검증해 건수·바이트·검증기 SHA·시간·실행 ID를 고정한다. B6에서는 실제 NAS CAS 파일의 구성요소를 읽지 않았다. 가상 스트림 해시가 과거 메타데이터를 실제 운영 성공으로 바꾸지 않는다.
- macOS 그룹 타임아웃은 B4 회귀에서 실제 가상 프로세스를 대상으로 검증한다. B5/B6의 세션 이탈 자식은 그룹 신호만으로 정리할 수 없음을 보였다. 운영은 독립적인 잔존 검사, 매체 소유 ID 및 마운트 상태 확인 전 재시도를 차단해야 한다. 실제 마운트·복원 및 잔존 대응은 별도 수용 시험이다.
- 기존 엔진 Gate v0.3·선택기 v2.1·CAS v0.2는 동일 바이트 조건부 재사용 후보이다. 쓰기 격리가 기존 코드와 양립하지 않거나 원본 영수증 및 전체 CAS 증거를 안전하게 얻지 못하면 운영용 새 진입부 또는 엔진 판본이 필요하다.
