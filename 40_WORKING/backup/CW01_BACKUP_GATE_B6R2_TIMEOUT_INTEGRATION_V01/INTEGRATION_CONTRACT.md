# B6-R2 격리 통합 계약

기존 B4 증거 파서·상태 전이와 B6 영수증·CAS 바이트 검증기를 재사용한다. 통합 OneShot은 실제 Gate나 NAS 엔진 대신 고정된 R2 시험 자식을 실행한다. R1의 수명주기 코드는 시험 자식 호출과 결과 전달부만 확장했다. 기존 승인 및 시험 원본은 보존한다.

- 예약·수동 진입은 같은 상위 flock을 잡는다. 그 잠금은 Gate → NAS → B6 증거 확인 → 결과 기록까지 유지한다. lock inode와 핀을 사전·사후 대조한다.
- 상위 ACTIVE와 단계별 pending은 자식 실행 전에 영속 기록한다. R1의 READY·DONE 토큰, 실제 자식 종료, 파이프 EOF 및 관측된 PID를 확인한 경우만 단계 결과를 증거 파서에 제공한다. 0.8초 시험 작업의 기존 지연은 그대로 유지한다. 시작·활성 작업·정리 기한을 각각 관리한다.
- 직접 생성한 시험 자식만 신호 대상으로 한다. 이탈 자식은 자체 종료까지 관찰한다. 종료 거부, 잔존, 매체 상태 불명확, 핀 또는 inode 변경에서는 승인된 새 작업을 시작하지 않는다.
- 재시작은 기존 ACTIVE·UNRESOLVED·pending을 보존한다. 확인된 자식 종료와 매체 상태, 명시적 검토, 연결된 단계 ID를 요구한다. 정보가 부족한 ACTIVE나 핀·잠금 사고는 자동 해제 대상에서 제외한다. 실패 영수증은 보존한다.
- B4 기준의 신규/재검증/건너뜀/실패 구분을 시험한다. R2가 신규 바이트를 검증해도 상태는 CANDIDATE_NEW_EVIDENCE이며 실제 성공·배포 필드는 false다. B4 원본 실행 결과와 통합 후보의 결과는 각각 보존한다.
- 실행 및 결과는 시험 폴더 안으로 한정된다. 동일 UID의 악의적 파일 조작 차단, 실제 매체 상태 관측, 실제 엔진·자식 추적, v043 서명·배포·전용 쓰기 자격은 운영 승인 후 검증할 항목이다.

운영 단계 전에는 승인된 신원과 코드 핀, 실제 엔진 및 로컬·NAS 증거, 실매체 상태와 재진입 관측, 전용 쓰기 권한, 롤백을 확인한다. 11월 8일 조사 B는 기존 정기 실행의 읽기 전용 판정이다. Step 5-C는 BLOCKED다.
