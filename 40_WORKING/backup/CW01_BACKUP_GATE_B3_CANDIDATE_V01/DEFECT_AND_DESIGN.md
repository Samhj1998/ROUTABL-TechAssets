# Backup Gate B3 결함과 격리 설계

## 관찰과 가상 재현

Backup Gate B2 조사 A는 04:30 KST에 native.v042와 native.v02가 모두 예약되어 있고, 감독자 v0.2와 v0.1이 별도 잠금을 사용하면서 동일 OneShot과 그 공용 잠금으로 진입함을 확인했다. OneShot의 잠금 충돌 분기는 Gate 호출 전에 ALREADY_RUNNING_SAFELY_SKIPPED와 backup_executed=false를 반환하고 종료값은 0이다. Gate에도 ALREADY_RUNNING과 executed=false를 반환하는 별도 잠금 분기가 있다. 감독자 v0.2는 자식 출력을 버린 후 종료값 0과 기존 영수증 연결을 사용한다. 그 연결만으로는 당일 신규 작업이나 현재 대장 일치를 확인할 수 없다. 구조적 결함은 CONFIRMED다.

2026-11-07 04:30 실행에서 실제 잠금 충돌 여부, Gate 도달 여부, 이전 감독자 실패의 세부 원인은 ROOT_CAUSE_UNVERIFIED다. 14번은 그날의 로그를 재구성한 것이 아니라, 코드의 거짓 성공 조건을 가상 v0.19 영수증과 모의 자식 결과로 재현한 시험이다.

B2 인계 기준 최신 대장은 v0.27, 162건, SHA-256 afe17adb54103952c0e84d296ded42a478fca49f25bd53f1f87dc0c73e1ce244다. 기존 계보는 2026-11-06 로컬 스냅샷 ASSET_V21_20261106_043146_KST_59950 및 해당 NAS CAS다. 대장은 v0.19, 대장 SHA-256 f8c6837c4d2a238c5d5ebe66df1c3ee5c9ba77d3dda3e2aa59222684b4d3e49b, 선택 목록 SHA-256 cbaed80d42349dd3ac38c20078f0e04db7a086039714ec698508abf83d50f8a5, 로컬 영수증 SHA-256 522768f65f52c270c7c079fd43a0335258052d78f0e144f4b43cea1da9813070이다. 이는 B2 증거 참조다. 최신 v0.27 보호 및 전체 복원은 NOT_VERIFIED다.

## 후보의 입력과 판정

감독자는 지정 예약 1개와 세 프로그램 고정 해시를 요구한다. 예약 진입과 수동 진입이 동일 잠금 소유권을 존중한다는 운영 어댑터 계약을 전제한다. 잠금을 보유한 상태에서 기준 인벤토리와 이전 영수증을 읽고, 로컬 → NAS → 최종 증거 순서로 진행한다. 실행기는 프로세스나 운영 파일을 열지 않고 주입된 구조화 결과를 검증한다.

| 상태 | 판정 |
| --- | --- |
| NEW_BACKUP_VERIFIED | 로컬 신규 작업과 다른 스냅샷 ID, 이번 실행 시각 범위, 새 NAS 복제 작업, 계보 검증 및 인벤토리 재대조 |
| CURRENT_BACKUP_ALREADY_VERIFIED | 실행 전부터 존재한 당일 로컬 영수증과 NAS CAS가 동일하고 현재 인벤토리와 계보를 재검증 |
| SKIPPED_LOCK_HELD | 상위 공유 잠금 또는 자식 잠금에서 작업 없이 종료 |
| NO_NEW_BACKUP_EVIDENCE | 종료값 0이더라도 실행 증거가 없거나 신규·재사용 주장에 시각 또는 이전 증거가 맞지 않음 |
| STALE_REGISTRY_BACKUP | 로컬 영수증이 현재 대장·선택 목록·선택 건수·총바이트와 다르거나 날짜가 오래됨 |
| NAS_CHAIN_NOT_VERIFIED | CAS 누락·불일치·미완료 또는 최종 검증 증거 부족 |
| FAILED_SAFE | 잘못된 예약 구성, 고정 해시 불일치, 불완전한 계약, 비정상 종료, 타임아웃 또는 기준 변동 |

신규 작업 완료와 기존 당일 백업 검증을 분리한다. 실제 작업은 했지만 검증이 실패할 수 있고, 타임아웃은 작업 여부를 모를 수 있다. 각 단계의 고정 상태 코드, 종료값, 작업 여부, 실행 ID, KST 시각, 필요한 검증 식별자만 구조화한다. 원문 자식 출력과 예외 메시지는 보고하지 않는다. 시험의 시각과 해시는 가상 값이다.

## 잠금과 어댑터 경계

운영에서는 예약·수동 경로 모두에서 하나의 공유 실행 잠금을 보유하고 최종 검증까지 해제하지 않는 규약이 필요하다. 새 감독자가 보유한 잠금을 자식이 다시 독립 획득하는 구조는 피한다. 한 소유자가 보유한 토큰/FD를 검증하는 계약을 별도 시험한다. 기존 Gate와 selector의 내부 잠금은 보호 목적을 유지하되, 재진입·잠금 순서·이전 수동 도구의 우회 경로를 수용 시험에서 확인한다. 프로세스 잠금, 프로세스 종료, 승인 파일, 키체인, 매체와 연결되는 운영 어댑터는 이 후보에 포함하지 않는다.
