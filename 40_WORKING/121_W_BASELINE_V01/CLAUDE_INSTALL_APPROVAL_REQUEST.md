# 121 Chat 승인 검토안

## 지금 결정할 범위

1. **설치만**. MacStudioui-MacStudio.local (c377300b-a710-43a6-8169-f17e87175403)에서 Homebrew stable cask 한 건을 설치하고 claude --version과 실행 경로를 확인할지 결정한다. 후보 명령은 CLAUDE_INSTALL_READINESS.md에 있다. Homebrew 갱신과 다른 패키지 설치는 별도 결정 사항이다.
2. **계정 확인**. 사용자가 승인한 경우 사용자 본인이 Claude Pro 계정으로 OAuth 인증한다. Settings > Usage에서 사용량 크레딧/자동 충전 비활성 및 개인 정보 옵션을 확인한다. 인증 관련 비밀을 보고서에 기록하지 않는다. 첫 실행에서 독립 분석 자료를 입력하는 절차와 분리한다.
3. **격리 검증**. 승인 후 별도 디렉터리와 입출력 경계를 만들고 무해한 경계 파일로 읽기·쓰기·MCP·셸·상위 경로 차단을 검증한다. 별도 로컬 사용자나 OS 권한 변경이 필요하면 승인 범위를 명시한다.
4. **외부 제공 승인**. 격리 시험 PASS 후 승인할 파일을 SHA 단위로 지정한다. 해당 목록의 준비와 Anthropic 모델 처리 전송을 별도로 검토한다. B/C 모두 승인된 동일 입력을 사용한다.

운영 SQL·검색 서비스 및 공식 대장 변경, API 결제, 추가 사용 크레딧, 원본 전송, 보류 자료 제공은 이번 승인안의 대상이 아니다.
