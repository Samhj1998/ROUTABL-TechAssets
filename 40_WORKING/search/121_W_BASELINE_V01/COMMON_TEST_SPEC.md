# 121 B·C 공통 평가 규격 v0.1

## 입력·비교

- A는 ASSET-SEARCH-01 v1.5, B는 ChatGPT Work, C는 Claude Code. 동일 Mac Studio·SQLite·코퍼스·인자에서 비교한다. 정렬·중복·검증·페이지 계약을 먼저 확인한다.
- 공통 입력 후보는 COMMON_ANALYSIS_PACKET_V01.md, 이 규격, SYNTHETIC_CORPUS_V01.json, SYNTHETIC_DEV_V01.json. 제공은 별도 승인 후. 각자 동일 SHA·판본·시험 규격만 받는다.
- 실운영 회귀 M04는 기존 9건의 R ID·범위·기대 개수만 공통 제공 후보로 한다. 정확한 기존 질의 문자열과 실제 결과 경로는 평가자 전용으로 유지한다. 평가자가 동일 9건을 A/B/C에 로컬로 수행한다. 공개용 합성 30건은 쿼리와 정답을 포함한다.
- 보류 20건, 예상값, 생성기, 집계 결과는 평가자 전용. B와 C의 최초 문서와 SHA-256을 각각 동결하기 전 서로의 결과를 교환하지 않는다. 보류 자료가 사전에 열람되었거나 관련 결론이 노출된 세션은 평가자 역할로 제한하고, 독립 분석은 승인 패킷만 받은 새 세션에서 수행한다.
- 두 팀은 변경 제안과 이유를 별도로 기록한다. 평가자는 동일 후보 정규화와 동일 fixture에서 평가하며 원본 DB나 원본 저장소 전체를 제공하지 않는다.

## 정확도

- relevance grade 3은 현재 대표 그룹, 1은 관련 구판 그룹, 0은 무관 그룹. 동일 그룹 중복 반환은 두 번째부터 0점. 그룹 ID는 qrels의 경로 매핑으로 정규화한다.
- Recall@10은 반환한 관련 그룹 수/전체 관련 그룹 수. Precision@10은 반환한 관련 그룹 수/10. MRR@10은 첫 관련 그룹 순위의 역수, nDCG@10은 2^grade-1과 log2(rank+1)으로 계산한다. 빈 결과는 0이며 질의별 계산 후 macro 평균한다.
- 중복은 예상 대표 경로, 개수, 위치 목록, 그룹 단일 반환 일치. 최신/검증은 대표 경로·SHA·status·provenance에 기록한 version 확인. 최신 자동 추론은 별도 시나리오로 검증한다.
- 필수 기존 회귀는 9/9. 원본의 반환 순서·점수·페이지·중복 개수 및 위치·검증 상태를 비교한다. 회귀 변화가 필요한 의도적 기능은 별도 승인과 개별 기대값을 갖춘다.

## 성능

- 질의는 유형별 및 질의별 결과를 보고하고, 후보 비교 시 동일 반복 30회 이상, 순서 회전, 단일 실행, 타이머 및 반복 수 통일. 새 프로세스 첫 호출, 새 연결 반복, 재사용 연결 반복을 별도 표기한다. OS 캐시 강제 비우기는 수행하지 않는다.
- HTTP end-to-end와 query 함수 내부 시간 분리. SQLite 준비·행 fetch, Python 후처리, 연결·응답 직렬화를 분리하며 p50/p95는 nearest-rank. 실패·타임아웃은 별도 보고.
- 인덱스는 승인된 격리 데이터에서 full, 변경 1건 및 배치, 무변경, 삭제·이름 변경을 나눠 시험한다. 소스 파일 읽기, 이전 DB 복제, SQL 쓰기, 검증/교체를 따로 계측한다. 저장 공간은 DB와 인덱스별 bytes를 기록한다.
- 현재 결과의 합성 코퍼스는 제어용이며 운영 분포를 대신하지 않는다. 실제 작업 유형별 합성 규모 확대 및 운영 latency 목표치는 Chat에서 확정한다. 기존 회귀 유지와 정확도 악화 방지를 선행 조건으로 삼고, 그다음 속도·갱신비용·저장공간을 비교한다.
