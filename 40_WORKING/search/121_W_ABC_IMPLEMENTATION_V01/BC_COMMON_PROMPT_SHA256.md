# 공통 독립 구현 지시문 SHA-256

사용자 지시의 공통 본문을 UTF-8 LF로 저장했다. 본문의 Markdown 이스케이프와 마지막 줄바꿈을 유지했다. 바이트 3,895, 모드 0400. 두 사본과 C 최초 stdin은 동일 바이트다.

- B `/Users/yongho/121_CHATGPT_B_V01/implementation/IMPLEMENTATION_COMMON_PROMPT.md`
- C `/Users/yongho/121_CLAUDE_ISOLATED_V01/implementation/IMPLEMENTATION_COMMON_PROMPT.md`
- 공통 SHA-256 `e22dd54c0a9047c5d5e72f282d98bcc75ba8f28dfa9d854c672ebbd4899402c0`

각 세션의 실행 안내는 디렉터리, 검증, 허용 도구와 시험 실행 명령만 다룬다. 공통 지시문에 상대 해법이나 평가자 정보는 추가하지 않았다.
