# Step 2-B 실행 경계 및 Step 2-C 승인 후보

이번 실행에서 Work가 직접 수행한 작업은 장치 연결, 설치 바이너리 해시와 버전 재확인, 인증 명령 도움말 확인, 원격 환경 변수 이름의 존재 여부 확인 및 이 보고서 작성이다. 실제 Mac Studio 터미널의 환경 점검은 사용자가 실행했으며 결과는 40개 모두 ABSENT였다. 실제 사용자 터미널의 Pro 인증 경로와 계정 일치는 사용자 제공 출력에서 확인했다. 사용자는 OAuth 항목을 확인했다고 보고했다. 신규 실행 여부는 명시되지 않았다. 제공된 화면에서 Pro, Usage credits 꺼짐, 잔액 US$0을 확인했으며 자동 충전은 표시되지 않았다. 보고서에는 인증 비밀, 브라우저 데이터, 원시 인증 출력을 담지 않는다.

121 Chat이 Step 2-B의 남은 판정 기준을 검토한 후 Step 2-C는 별도로 승인한다. 제안 범위는 전용 작업 경로와 읽기 전용 입력·쓰기 허용 출력 경계 구성, 무해한 시험 파일로 CLI와 셸의 외부 접근 차단 및 심볼릭 링크·상위 경로 검증, 설정 자동 로딩과 실효 MCP 목록·허용 경로 확인이다. 새로운 macOS 사용자, 권한 변경 또는 실제 모델 호출이 시험에 필요해지면 승인 범위를 별도 명시한다. 공통 자료 배치와 외부 전송, B/C 분석·개발은 별도 승인이다.
