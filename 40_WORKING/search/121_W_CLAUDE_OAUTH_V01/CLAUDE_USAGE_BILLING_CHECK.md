# Claude 구독 및 추가 과금 확인

| 항목 | 상태 | 증거 |
|---|---|---|
| 개인 Claude Pro | PASS | 실제 터미널에 Claude Pro account 표시, 사용자 제공 사용량 캡처 상단 Pro 표시 |
| Usage credits 활성 여부 | PASS · 비활성 | 사용자 제공 캡처의 토글 꺼짐 |
| Usage credits 잔액 | US$0 | 사용자 제공 사용량 캡처 표시값. 결제 내역은 미확인 |
| 자동 충전 설정값 | NOT_TESTED | 사용자 제공 캡처에 항목 표시 없음 |
| Console 계정 존재·별도 자동 충전 | NOT_TESTED | 존재 및 접근 가능 여부 미확인 |

사용자 확인 화면은 Claude Settings > Usage이며, 필요한 경우 같은 계정의 요금제 화면도 함께 확인한다. 꺼짐과 표시 없음은 따로 기록한다. Console 상태는 개인 Pro 구독 화면과 구분하며, 기존 계정에 접근할 수 있는 경우에만 읽기 전용으로 확인한다. 프로젝트 허용 기준은 Usage credits 비활성, 자동 충전 비활성, 별도 API 사용 없음이다.
