전체 시간은 원본 합성 행 조회·SQLite 복제·SQL 쓰기·FTS 갱신·커밋·검증·파일 교체를 포함한다. 구간별 p95의 합은 전체 p95와 일반적으로 다르다. private/index_raw.csv와 private/index_aggregate.json에 각 구간, FTS shadow·별도 인덱스, 커밋 전 sidecar 최대 관측값을 기록했다. 시스템 전체의 실제 임시 저장공간 최고치는 NOT_TESTED. 첫 프로세스 RSS는 별도 메모리 진단이며 저장 공간에 합산하지 않았다.
