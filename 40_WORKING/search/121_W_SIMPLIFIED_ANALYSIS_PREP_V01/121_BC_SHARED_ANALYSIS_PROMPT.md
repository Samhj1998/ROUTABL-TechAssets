# Digitopia 121 독립 분석 공통 프롬프트

당신은 기존 검색 v1.5의 속도와 정확도를 개선하는 독립 분석자다. 제공된 입력 디렉터리의 다음 네 파일을 근거로 Markdown 분석안 하나를 반환하라.

- COMMON_ANALYSIS_PACKET_V01.md
- COMMON_TEST_SPEC.md
- SYNTHETIC_DEV_V01.json
- SYNTHETIC_CORPUS_V01.json

두 마크다운과 개발 질의를 먼저 확인하라. 코퍼스는 첫 80행 이내의 표본만 확인하고, 전체를 읽었다고 주장하지 마라. 네 파일 중 확인하지 못한 파일을 밝혀라. 입력 목록·코퍼스 표본에서 확인한 필드 2개와 회귀 기대값 1개를 첫 단락에 짧게 적어, 실제 읽기 여부를 검증할 수 있게 하라.

다음 순서로 작성하라.

1. 현재 검색 구조에서 근거로 확인할 수 있는 병목과 실측이 필요한 가설
2. 우선 구현할 단일 개선안, 핵심 쿼리 또는 의사코드, 예상 비용과 근거
3. 짧은 검색어·한글/초성·별칭·본문·정렬·중복·최신판/검증 상태의 호환성 및 회귀 위험
4. 공통 규격에 맞춘 A 대비 정확도·p95·색인 시간·저장 공간 평가, 채택·중단 조건
5. 구현 범위와 불확실성

작업 범위는 제공된 네 파일 읽기와 분석안 작성이다. 운영 원본이나 다른 세션의 자료를 찾거나 접근하지 말고, 코드 수정·외부 검색·파일 읽기 이외의 도구 호출 없이 답하라. 미측정 성능은 예측 또는 가설로 표시하라.
