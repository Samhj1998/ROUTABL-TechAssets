# 120. 라우터블 기술자산 통합검색 v1.5 — Mac에서 사용하기

작성: 2026-11-03 | 대상: Mac Studio | 기존 v1.4 보존

## 검색 앱 열기
1. Finder에서 `Shift + Command + G`를 누릅니다.
2. `~/Applications`를 입력합니다.
3. **라우터블 기술자산 검색 v1.5.app**을 더블클릭합니다.
4. 기본 브라우저에 로컬 검색 화면 `http://127.0.0.1:8769/`이 열리면 정상입니다.

기존의 **라우터블 기술자산 검색.app**은 v1.4이며 정상 보존되어 있습니다.

## 검색과 자료 확인
- 검색창에 `정산`, `고객`, `초성검색`, `시니어`, `TransportStatusPolicy`, `cloud_access.py` 같은 검색어를 입력합니다.
- 한글 2글자부터 검색됩니다. 검색어에 따라 관련된 영문 명칭도 함께 찾습니다.
- **범위 선택**: 전체 자료 / 주요 개발 프로젝트 / 과거·파생 작업본 / NAS·보관자료.
- 결과는 12건씩 페이지로 나뉩니다. 하단 **이전 페이지 / 다음 페이지**로 이동합니다.
- 동일 SHA-256인 파일은 대표 원본 아래 **동일 파일의 다른 보관 위치**로 묶어 표시합니다.
- 확인된 자산 ID, GitHub 보관 경로, NAS 사본은 검증 증거가 있는 경우에만 표시합니다.
- Mac 원본 검색 결과에서 **Finder에서 위치 보기**를 누르면 Finder가 파일 위치를 표시합니다. 파일 자체를 실행하거나 자동 수정하지 않습니다.

## 새 파일이 검색되지 않으면
- 화면 우측 상단 **검색 목록 새로 고침** 버튼을 누릅니다.
- 로컬 소스파일을 다시 읽어 검색용 목록을 만듭니다. 이 동안 기존 검색은 계속 가능합니다.
- 갱신이 성공하면 직전 검색 DB를 복구용 파일 1개로 보관하고 새 DB를 적용합니다.
- 갱신에 실패하면 기존 색인을 계속 사용합니다. 원본 파일과 NAS·GitHub는 수정하지 않습니다.
- 이전부터 SHA-256으로 고정 검증된 기준 파일이 변경된 경우, 이력 보호를 위해 갱신을 보류합니다.

## 보안·중복 실행
- 서버 주소는 Mac 자신을 뜻하는 `127.0.0.1`이며, 외부 웹사이트로 기술자산을 업로드하지 않습니다.
- 화면의 갱신과 Finder 위치 열기는 동일 출처·임시 승인 토큰을 검사합니다.
- 인증키·비밀번호·민감 개인정보 원문은 기존 v1.3 정책에 따라 검색 대상에서 제한됩니다.
- 브라우저 탭이 있어도 검색/페이지 이동 등 실제 이용이 45분 이상 없으면 서버는 자동 종료됩니다.
- 앱을 두 번 눌러도 같은 검색 서버를 여러 개 실행하지 않습니다.
- **Terminal.app, 로그인 자동실행, launchd 예약 작업을 사용하지 않습니다.**
- 앱의 데이터 조회는 원본 보호를 위한 것이며 파일 자체의 변경은 하지 않습니다.

## 실행 파일과 되돌리기
- Mac 앱: `~/Applications/라우터블 기술자산 검색 v1.5.app`
- 검색 서비스: `~/Library/Application Support/ROUTABL-AssetSearch/routabl_search_v1_5_service.py`
- 검색 DB: `~/Library/Application Support/ROUTABL-AssetSearch/assets_v1_5.sqlite`
- 직전 검색 DB: `~/Library/Application Support/ROUTABL-AssetSearch/assets_v1_5.previous.sqlite`
- 이전 안정판: `~/Applications/라우터블 기술자산 검색.app` (v1.4)
- 백업 대용으로 검색 DB만 보관하는 것은 불충분합니다. 코드 원본, 백서, NAS 백업은 별도로 보존해야 합니다.

## 현장 최종 확인이 남은 항목
- 실제 Finder 더블클릭 후 기본 브라우저에 v1.5 화면 표시 여부.
- 실제 마우스로 **검색 목록 새로 고침** 버튼을 누른 뒤 결과 표시 여부.
- 실제 마우스로 **Finder에서 위치 보기**를 눌렀을 때 Finder가 올바른 파일을 선택하는지 여부.

Mac LaunchServices를 통한 앱 기동, 검색 API, 서버 중복 방지, 수동 갱신·복구 파일,
지정 외 경로 차단 및 자동 종료는 프로그램 검증을 통과했습니다.
