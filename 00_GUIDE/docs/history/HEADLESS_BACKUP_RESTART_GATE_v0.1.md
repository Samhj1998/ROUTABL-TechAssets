# 120. 자동 백업 안전 재개 안내 v0.1

**현재 상태: 보류. 기존 Mac·NAS·Drive 자동 백업 3개는 비활성화 상태.**

## 지금 완료한 것
- 무한 Terminal 창 재발을 막기 위한 **GUI 없는 Python 실행 설계** 초안 제작.
- 새 백업 예약 설정 2개(로컬 04:30, NAS 05:15)를 **설치하지 않은 상태로만 보관**.
- 무인 파일 접근 권한·Keychain을 건드리지 않는 모의실행에서 단일 실행/중복 방지 통과.
- 기존 자산대장 v0.7 33개 중 현재 암호화 백업 규칙상 포함 가능한 파일은 5개로 확인.

## 지금 하면 안 되는 것
- 기존 3개 com.routabl.assetbackup... 예약 작업 재활성화.
- Terminal.app으로 .command 예약 실행 방식 재사용.
- 새 plist를 승인 없이 ~/Library/LaunchAgents에 설치.
- 개인 패스키·비밀번호·관리자 SDK 원본을 검색 인덱스/로그/공유 파일에 추가.
- 과거 성공 영수증만 보고 오늘 새 기술자산도 백업됐다고 보고.

## 다음 실행 안전 관문
1. 백업에 포함할 일반 기술자산을 원본 기준으로 확정하고 해시 기준 등록.
2. 사용자에게 실제 변경·복원 계획과 백업 범위 제시.
3. 격리된 시험 입력으로 단발 백업 동작 검증.
4. 실제 스토리지 접근이 필요한 단발 시험은 승인 후 수행; 암호화 해제/재잠금 및 임시 복원 SHA 검증.
5. 시험 완료 판정 이후에만 로컬·NAS 예약 설치와 첫 무인 실행 검증.
6. Google Drive 자동화는 마지막 독립 오프사이트 수단으로 분리 검토.
