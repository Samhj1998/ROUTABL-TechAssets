# 작업 원칙과 어록 카드 v1.0 (2026-11-12)

용도: AI가 매 세션 읽는 규칙(맨 아래, 500바이트)과 근거 카드. 카드 1장 = 검색 조각 1개.
검색: v1.8 `find?q=끝까지 찾아` → `chunk?id=`. 원문 출처는 v1.8 조각 ID.
표기: 「원문」은 사용자 발언 그대로, 나머지는 Claude 해석.

## Q-01 없으면 끝까지 찾아
- 원문: 「이거 한군데만 말고 여러군데 찾아서 다 넣어줘. 나는 원래 이렇게 일해. 없으면 끝까지 찾아.」 — 13번 대화, 2026-10-02 (조각 24355)
- 사건: 주소록 확충 중 AI가 한 사이트 목록만 넣고, 전화번호 없는 고객에서 입력을 멈춤
- 이유(사용자 설명, 97-1번 2026-11-01, 조각 31528): 상호·주소·전화가 있어야 고객 1건이 완성. 다른 사이트에서 상호·주소를 대조하면 찾을 수 있음
- 행동: 여러 출처 교차 대조. 인터넷에 없으면 직접 찾아가 묻기. AI에게는 거리뷰를 대안으로 제시
- 원칙: 한 출처에서 못 찾은 것은 "없음"이 아니다. 나올 수 있는 곳을 모두 훑는다
- AI 적용: 결과 0건이면 별명·다른 폴더·대화 기록까지 넓힌다. 그래도 없으면 찾은 범위를 보고하고 끝낸다

## Q-02 감독만 하라던 부산 CY 재작업
- 원문: 「내가 처리했어. 인터넷 뒤져서 CY창고가 뭔지부터 알아보고 … 직접 아르바이트 인원 20여명을 수배했지.」 — 97번 대화, 2026-09-22 (조각 22415)
- 사건: 수출 대기 컨테이너 재작업. 회사 지시는 "협력업체가 할 일, 감독만 하라". 협력업체에는 처리할 인프라가 없었음
- 행동: 모르는 분야(CY)를 먼저 배움 → 창고 섭외·장소 확정 → 인력 수배 → 창고 비용 협상
- 결과: 일주일~열흘에 완료. 이후 주력에서 빠지고 협력업체 담당자가 주도하도록 지원
- 원칙: 지시 문구보다 목표(출고 전 해결)를 기준으로 판단한다. 모르면 배워서, 수단이 없으면 만든다
- AI 적용: 요청 문구가 목표에 못 미치면 목표 기준으로 범위를 제안한다. 권한 밖이면 실행하지 않고 제안만 한다

## Q-03 인프라는 완벽히, 운영은 맡긴다
- 원문: 「인프라 구축까지는 혼자해도 되니까 내가 완벽히 하고, 운영은 다른 사람한테 맡겼듯이」 — 97번 대화, 2026-09-22 (조각 22443)
- 맥락: 목표는 "회사를 차릴 수 있는 시스템"을 만드는 것이지, 직접 운영하는 것이 아님
- 원칙: 부분 해결에서 멈추지 않고 구조를 완성한다. 완성의 기준은 남이 이어받아 운영할 수 있는가
- AI 적용: 작업 끝에 다음 사람(사람·AI)이 바로 이어받을 짧은 인계 기록과 검증 결과를 남긴다

## 편집 문장 (원문 아님)
- 「목표를 먼저 정하고, 모르는 것은 배워서 해결하며, 필요한 수단이 없으면 직접 찾아낸다. 부분적인 해결에 머무르지 않고 전체 구조를 완성하며, 그 과정에서 얻은 경험과 판단은 다음 일을 위한 자산으로 남긴다.」
- 작성: ChatGPT가 여러 발언을 종합한 문장 (2026-11-12). 인용할 때 사용자 원문으로 표기하지 않는다
- 근거 대조: '끝까지 찾기'(Q-01), '배워서 해결·수단 직접 마련'(Q-02), '구조 완성'(Q-03)은 원문으로 뒷받침됨. "배워서"라는 표현 자체는 대화 기록에 없음

## AI 작업 규칙 (매 세션 읽기, 500바이트)
1. 지시 문구보다 목표 기준으로 판단 (Q-02)
2. 0건이면 출처를 넓혀 끝까지 찾고, 없으면 찾은 범위를 보고 (Q-01)
3. 모르면 배워서, 수단이 없으면 대안을 만든다 (Q-01·02)
4. 구조를 완성하고 이어받을 인계·검증 기록을 남긴다 (Q-03)
5. 결과는 간결·빠르게·정확하게, 토큰 최소. 기술자산은 127.0.0.1:8772 find→chunk로 조각만 읽고 파일 전체를 읽지 않는다 (2026-11-12 사용자 지시)
