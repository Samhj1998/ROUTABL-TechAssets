# 120. 검색 v1.5 — 사용자 Finder 실기기 확인 기록
기준일: 2026-11-03 KST
근거: 사용자 제공 두 장의 Safari 및 Finder 화면 (원본 스크린샷은 본 Mac 감사 폴더에 별도로 복제하지 않음).

## 실기기 확인
- Safari 127.0.0.1 v1.5 검색 화면에 TransportStatusPolicy 입력.
- 검색 결과 첫 항목이 검증된 기사앱 정식 원본 TransportStatusPolicy.kt로 표시됨.
- 해당 항목에 자산 ID INTEGRATION-F1, GitHub 확인 링크, NAS 사본 경로, 동일 SHA-256 9개 위치 표시됨.
- 'Finder에서 위치 보기' 클릭 결과 Safari의 위치 표시 안내와 Finder 내 TransportStatusPolicy.kt가 선택된 화면 확인.
- 원본 소스 실행/편집·Firestore 변경 증거는 아님.

## 사용자 확인 미완료
- '검색 목록 새로 고침' 버튼을 사용자가 실제 누른 후 최종 상태까지 확인한 화면은 없음.
- 새로 고침의 프로그램 자동 시험은 통과했으나 이를 실기기 수동 시험 완료로 기록하지 않음.

## 보존
- 이 파일은 사용자 화면 확인을 텍스트로 기록한 감사 메타데이터.
- 실제 이미지 파일이 NAS/Drive에 백업됐다고 주장하지 않음.
