- 로컬 공식 내보내기 ZIP에 수록된 .dat 파일 데이터 2,529개 전체를 읽고 정확한 UTF-8 문구를 검사.
- 첫 문서: 파일 데이터 내부 **문구 발견(PASS)**.
- 두 번째 문서: 파일 데이터 내부 **문구 발견(PASS)**.
- 파일명 매핑에서는 라이브러리 원본명과 직접 일치하지 않아도 파일 데이터 안에는 내용이 포함될 수 있음이 확인됨.
- 정밀 크로스워크를 위한 파일 ID·원본 전체 바이트 SHA-256 대조는 수행하지 못함. 따라서 두 파일의 모든 바이트가 라이브러리 최신 버전과 완전히 일치한다고 판정하지 않음.

- 기존 LIBRARY_AND_ATTACHMENTS_CROSSWALK_v0.1.md의 '표본 192개 중 파일명 일치 4개'는 **원본 누락 188건**이 아니며, 이 추가 검증은 파일명 불일치에도 내용이 수록될 수 있음을 실증함.
- ChatGPT 라이브러리 전체에 관한 포괄적 포함률이나 모든 파일의 원본 무결성은 여전히 **검증되지 않음**.
- 내보내기 ZIP 및 라이브러리 원본을 수정·삭제·외부 공유하지 않음.
- 전체 파일 일치·동기화/복원 성공 여부는 향후 개별 파일 SHA-256 또는 승인된 원본 바이너리 접근을 통해 확정해야 함.
