# 120-1. 라우터블 ChatGPT 아카이브 v0.4 — 레이아웃 회귀 수정 및 이전 버전 독립성 검증

**작성:** 2026-11-06 KST · Mac Studio · 사용자 명시 수정 승인.  
**요청:** v0.4에서 v0.3과 달리 좌우 배치가 세로로 무너진 원인을 수정하고, v0.1~v0.3 디스플레이 버전을 삭제해도 v0.4의 핵심 기능이 독립 작동하는지 확인한다.

## 1. 근본 원인
- v0.3 `index.html`은 `#v03-layout`을 사용하고 스타일 `v03-style.css`를 참조.
- v0.4 생성 프로그램의 파일 복제 목록에는 `style.css`, `project-style.css`, `search-data.js`만 포함하고 `v03-style.css`가 **누락됨**.
- v0.4 `index.html`은 `v03-style.css`를 계속 요청했으나 파일이 존재하지 않아 `#v03-layout{display:grid;grid-template-columns:290px minmax(0,1fr)}` 규칙이 적용되지 않았음.
- v0.4 `v04-style.css`는 Markdown 표·코드 서식이며 누락된 그리드 규칙을 포함하지 않았음.
- 이전 자동시험 15/15는 검색·숫자·표·본문 기능만 검증했으며 **로드되는 CSS 존재 여부·실제 열 배치 계산값을 시험하지 않은 회귀 테스트 누락**이 2차 원인.

## 2. 기존 버전 독립성 현황과 변경
수정 전 v0.4:
- 채팅 HTML 327페이지, 검색 데이터, 앱 코드는 별도 파일이지만
- `assets`가 `../10_GUI_VIEWER/assets`로 연결되는 **심볼릭 링크**여서 v0.1 삭제 시 이미지·첨부파일 1,925개 모두 열리지 않을 위험.
- `style.css`, `project-style.css`, `search-data.js`는 이전 버전과 같은 파일 내용을 가리키는 hardlink. 원래 경로 삭제에는 유지되지만, 기존 버전에서 파일을 수정하면 v0.4에도 영향을 줄 수 있어 완전한 변경 격리는 아니었음.

적용 후 v0.4:
- `v03-style.css`를 v0.3에서 **복사 온 라이트(APFS copy-on-write)** 방식으로 독립 복제해 누락 보완. HTML 파일은 변경하지 않음.
- 기존 hardlink로 공유한 3개 필수 파일을 APFS 독립 복제한 뒤 같은 이름으로 교체. 내용과 SHA-256은 이전과 같고 다른 inode를 가져 개별 변경 격리.
- v0.1의 첨부 파일 1,925개(논리 크기 합계 **1,619,366,714 bytes**)를 v0.4 자체 `assets/` 디렉터리로 APFS 독립 복제. 전 파일의 SHA-256을 원래 자료와 1:1 대조, 1,925/1,925 통과.
- 해당 첨부의 독립 SHA 목록을 `v04_independent_assets_sha256_20261106.json`으로 별도 보관.
- 변경/삭제하지 않은 파일: v0.4 `index.html`, `app.js`, `project-id-data.js`, `v04-style.css`, 대화 HTML 327페이지, 원본 ZIP 및 JSON, v0.1/v0.2/v0.3 전체, AES-256 백업.

## 3. 실제 브라우저 독립성 및 레이아웃 시험
자동시험 결과: **13/13 PASS**, 원본/과거 버전 변경 없음.

- 1450px 화면: CSS 4종 모두 로드됨. `#v03-layout` 계산된 `display:grid`, 열 크기 **290px + 1080px**, 프로젝트 사이드바와 채팅 패널 같은 y 위치의 좌우 배치.
- 780px 화면: 미디어쿼리로 의도대로 세로 배치.
- 로컬 브라우저에서 이전 버전 디렉터리 `10_GUI_VIEWER`, `11_GUI_PROJECTS_V02`, `12_GUI_PROJECT_IDS_V03`로의 요청을 **차단한 상태**에서 327건 전체, 라우터블 121건, 사용자 복원 확인 21건, Markdown 표/제목 정상 표시.
- 120번 상세 페이지의 이미지 12개 중 임의 첫 이미지 정상 로드: 실제 `naturalWidth=2048`.
- 네트워크 요청 또는 이전 디렉터리의 필수 자원을 요구하는 오류 없음.

## 4. 독립성과 삭제 범위 정확하게 설명
- **v0.1~v0.3 GUI 디렉터리만 삭제하더라도** v0.4의 검색, 프로젝트 메뉴, 채팅/Markdown, 로컬 첨부파일은 독립적으로 작동할 수 있게 개선 및 시험됨. **그러나 실제 삭제 시험은 하지 않았으며 삭제는 이번 작업 범위가 아님.**
- v0.4 `index.html` 하단에 남아 있는 **과거 버전 열람용 선택 링크 3개**와 **바탕화면의 과거 버전 바로가기**는, 해당 버전을 삭제하면 당연히 열리지 않음. 현재 v0.4 기능을 위한 의존 관계는 아님.
- v0.4의 `../00_EXTRACTED_ORIGINAL/chat.html` 링크는 독립적인 공식 원본 보관 위치를 가리킴. 그 원본 폴더를 삭제하면 원본 열람 링크가 끊김. 원본 ZIP 또는 압축 해제 원본 삭제를 승인하거나 권장하지 않음.
- v0.4는 2026-11-05 ChatGPT 내보내기를 표시하기 위한 **정적 오프라인 열람본**이다. Firebase를 실시간 조회하는 기사앱과 달리 ChatGPT 계정의 신규 대화·보관 상태·프로젝트 편집이 자동 반영되는 앱이 아니다. 사용자가 2026-11-06 직접 보고한 복원 19+2건만 별도의 확인 기록으로 추가함.
- 이 독립성 시험은 **필수 리소스 경로 차단/화면 렌더링 시험**이지 파일시스템에서 실제 v0.1~v0.3을 삭제한 후 재시도한 시험은 아니다.
